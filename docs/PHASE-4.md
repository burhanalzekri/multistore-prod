# المرحلة الرابعة — المصادقة والصلاحيات

## ما أُنجز

أضيف Auth.js v5 Credentials عبر `lib/auth.ts` و`/api/auth/[...nextauth]` بجلسة JWT مشفرة قصيرة العمر (8 ساعات). التسجيل والدخول والخروج عبر Server Actions؛ صفحات الواجهة هي `/login`, `/register`, `/account`, `/forgot-password`, `/reset-password`, `/verify-email`. أنماط المصادقة محصورة في Route Group فلا تدخل CSS صفحة Landing.

تُخزّن كلمة المرور بصيغة scrypt (N=32768، r=8، p=1) مع salt عشوائي 16 بايت ومفتاح 64 بايت؛ تحققها constant-time. حد الطول 12–128 محرفاً. رموز التحقق وإعادة التعيين 256-bit عشوائية، تخزن بصمة SHA-256 فقط، تنتهي بعد ساعة وتُستهلك مرة واحدة.

محاولات الدخول الفاشلة تُحدد بـ5 في 15 دقيقة، ثم حظر 15 دقيقة؛ المفتاح HMAC للبريد ولا يُخزن البريد في جدول الحدود. الصلاحيات الحساسة server-side: `requireSuperAdmin()` يعيد قراءة الدور من DB بدلاً من اعتماد claim قديم، و`requireCurrentShopRole()` يعتمد العضوية في متجر المضيف الموثوق.

أضيف `AuthRateLimit` إلى Prisma ومهاجرته التفاضلية في `prisma/migrations/20261009223000_auth_rate_limits/`. لم يُعدل أو يُطبق أي migration على قاعدة خارجية.

## التحقق

- `bun run test`: 10 اختبارات ناجحة، تشمل عزل المستأجر وحقول كلمات المرور.
- `bun run typecheck`, `bun run lint`, `bun run build`: ناجحة.
- صفحات الدخول والتسجيل والتحقق والاستعادة تعيد HTTP 200 على الرابط المؤقت؛ صفحة الحساب غير المسجل تعيد التوجيه إلى `/login`.
- فحص Chromium للهاتف والحاسوب: لا قص أفقي، لا أخطاء صفحة، والوضع الداكن المحفوظ يبقى فعالاً في صفحات Auth.
- حزمة JavaScript المشتركة لصفحة Landing بقيت 105 KB حسب build؛ CSS المصادقة منفصل في route group.

## الاعتماديات اللازمة قبل الاستخدام الحقيقي

المعاينة لا تملك PostgreSQL فعلياً، لذا لم تُختبر عمليات إنشاء المستخدم، وتغيير كلمة المرور، وعمليات rate-limit مع قاعدة فعلية. يجب تشغيل كل migrations على قاعدة Neon يملكها المستخدم قبل اختبار التسجيل. لا تُرسل المعاينة بريداً؛ يلزم ضبط `EMAIL_SERVER`, `EMAIL_FROM`, `AUTH_URL`, `AUTH_SECRET` و`AUTH_RATE_LIMIT_SECRET` سراً في بيئة النشر. في الإنتاج يُمنع تسجيل حساب جديد ما لم يكن SMTP مضبوطاً، ولا يسمح الدخول حتى تأكيد البريد. في التطوير المحلي يمكن اختبار التسجيل دون البريد. OAuth غير موصل في هذه المرحلة.
